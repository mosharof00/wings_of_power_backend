# T-BE-021 — Student Safe Space

**Status:** done
**Module:** `src/modules/safe-space`
**Depends on:** T-BE-006
**Priority:** P0

## Goal

A student can file a Safe Space report, list their own reports, and open one without seeing staff notes.

## Scope

`SafeSpaceModule`. Active student. Reports are not soft-deleted.

Create: `category`, `body` max 200, `feelSafe` boolean. Generate `public_ref` `WP-` plus four digits, unique. Set `school_id`, `student_id`, `class_id` from the approved membership when one exists, `status: NEW`, `submitted_at`. Return `public_ref`.

List filters by `status`. Detail is own row only (404 for others, not 403, so existence does not leak). Response has no note bodies and no note ids.

P1 on the same service: `POST /api/safe-space/visits` with optional `matchId`. Insert `SafeSpaceVisit`. Do not store free text. There is no body field for a journal.

## Out of scope

- Teacher and admin queues (T-BE-022).
- Pausing a live match (the gateway handles that in T-BE-026 by **not** pausing).
- Notifications.

## Notes

Categories are the `ReportCategory` enum only. Do not add a counseling endpoint. Retention is an open question; do not delete reports in this task.

Implementation notes:
- Implemented `SafeSpaceModule` with `StudentReportsController` and `ReportsService`.
- `POST /api/safe-space/reports`: validates category, body (<= 200 chars), and feelSafe boolean. Generates unique public_ref ('WP-' + 4 digits). Extracts school_id, student_id, class_id from approved membership when present (fallback to user.school_id). Sets status NEW and submitted_at.
- `GET /api/safe-space/reports`: returns paginated caller reports, filtered by optional status query param.
- `GET /api/safe-space/reports/:id`: returns report detail for caller only. Returns 404 for other students or non-existent id. Detail JSON contains no notes key.
- `POST /api/safe-space/visits`: records calm space visit with user_id and optional matchId without text/journal body.
- Unit tests cover all 6 required cases and edge cases. Built and passed test suite.

**Status:** done

**Depends on:** T-BE-016, T-BE-018, T-BE-020, T-BE-022, T-BE-027
**Priority:** P0

## Goal

One HTTP journey covers the student learning loop and a Safe Space report.

## Scope

Use the app helper from T-BE-028 if it exists. If this task runs in parallel with T-BE-028, copy a minimal boot helper into `test/helpers/app.ts` only when that file is absent; if it exists, import it. Do not rewrite the identity spec.

Flow, with an admin and an active student (seed or API):

1. Admin uploads are skipped if disk is local; create a story with a cover URL string, chapter, pages, audio URL.
2. Publish. Student `GET /api/stories` sees it. A second school’s story is absent (create another school only if the single-school rule makes that hard — then assert a draft is hidden instead).
3. Teacher PUT chapter quiz with one MCQ.
4. Student reads progress, answers, completes. Points `GET` shows a `STORY_QUIZ` row. Chapter complete marks the chapter done.
5. Admin PATCH a badge `criteria_json` to `{ "chapters_completed": 1 }`. Completing the chapter (or calling complete again if already done, then re-evaluate by completing the quiz path) earns the badge. `GET /api/badges` shows `earned: true`.
6. Student creates a Safe Space report. `GET` detail has no notes. Teacher list includes it. Admin adds a note. Student detail still has no notes.
7. Leaderboard returns the student with `kindnessPoints` 0 and no `real_name`.

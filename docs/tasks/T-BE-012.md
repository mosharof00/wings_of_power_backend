# T-BE-012 — Admin stories, chapters, pages, audio

**Status:** todo
**Module:** `src/modules/content`
**Depends on:** T-BE-011
**Priority:** P0

## Goal

An admin can create a story, publish it, and attach chapters, page text/images, and one audio file per chapter.

## Scope

`ContentModule`. Admin-only. School id comes from the caller. Story list is paginated and can filter `status`. Create defaults to `DRAFT`. Patch can set `PUBLISHED` and metadata (title, synopsis, cover URL, category, age group, estimated minutes).

Add chapter with the next `number` or a client-supplied number. Unique `(story_id, number)`. `PUT` pages replaces the page set for that chapter (same numbers, new body and `image_url`). `PUT` audio upserts the single `ChapterAudio` row (`audio_url`, optional `duration_ms`). URLs are strings produced by T-BE-011; this task does not upload.

Keep `chapter_count` equal to the number of non-deleted chapters.

Soft-deleted stories disappear from admin list (extension from T-BE-003). Do not add a public delete route unless you need one to satisfy the library screen. `docs/API.md` has no DELETE. Do not add DELETE.

## Required tests

- create is `DRAFT` and scoped to the admin’s school.
- patch to `PUBLISHED` persists category and age group.
- second chapter number collides → 409.
- pages PUT replaces previous pages rather than appending duplicates.
- audio PUT updates the same row on the second call.
- a teacher token → 403 (guard).

## Notes

Age group enum is `AGE_6_9 | AGE_10_13 | ADULTS`. If a client sends `14+`, reject it with 400. Mapping “14+” to `ADULTS` is already the database comment; do not accept the raw UI string unless you record that alias in `docs/DECISIONS.md` first. Prefer 400 so the dashboard sends the enum.

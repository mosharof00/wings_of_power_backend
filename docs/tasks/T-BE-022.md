# T-BE-022 — Staff Safe Space

**Status:** todo
**Module:** `src/modules/safe-space`
**Depends on:** T-BE-021, T-BE-007, T-BE-010
**Priority:** P0

## Goal

Teachers see reports for their classes. Admins see the school queue, assign a teacher, change status, and add private notes.

## Scope

Teacher list: reports whose `class_id` is a class they teach, or whose student has a membership in those classes. Teachers with `settings_json.canAccessSafeSpace === false` → 403.

P1 teacher detail and notes are in this task (same module, no teacher detail screen yet). Detail includes notes. Notes are staff-only.

Admin list: school, filter `status`, paginated. Detail includes notes and student nickname. Patch `status` (`NEW | REVIEWING | ADDRESSED`) and `assigneeId` (a teacher in the school). Admin notes: `author_id`, `body`.

No student token can read notes. Re-check the student detail service if T-BE-021’s method is shared: branch on role.

Do not soft-delete reports.

## Out of scope

- Creating the student report (T-BE-021).
- Email/push to the assignee (no endpoint).
- Match pause.

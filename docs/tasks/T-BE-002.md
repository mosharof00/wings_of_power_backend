# T-BE-002 — Rename app, config, and env

**Status:** done
**Module:** config
**Depends on:** T-BE-001
**Priority:** foundation

## Goal

Make env, config, and the README describe Wings of Power, and drop dependencies that only the deleted demos used.

## Scope

- `APP_NAME` example: `Wings of Power`.
- Hello string and e2e expectation match that name.
- Remove unused deps: `stripe`, `livekit-server-sdk`, `passport-facebook`, `puppeteer`, `qrcode`, `speakeasy`, `prom-client`, and matching `@types/*`. Refresh `yarn.lock`.
- `.env.example`: remove `GOOGLE_*`, `STRIPE_*`, `PAYPAL_*`, `LIVEKIT_*`. Keep Postgres, Redis, mail, JWT, AWS, GCP.
- Add `SEED_ADMIN_EMAIL`, `SEED_ADMIN_PASSWORD`, `SEED_TEACHER_EMAIL`, `SEED_TEACHER_PASSWORD`, `SEED_STUDENT_PASSWORD` with placeholder values (not a real password). Map them in `app.config.ts` `defaultUser`. Remove the old `SYSTEM_*` keys from the example after the config reads the new names.
- Document `JWT_EXPIRY` as **seconds**. Example value `86400`.
- Storage path keys for later uploads: `story-cover`, `page-image`, `chapter-audio`, `badge-art`, `hero-art`, `kindness-media`, `avatar`. Remove blog, portfolio, job-photo, post-community, and requests paths.
- Remove `payment` and `auth.google` blocks from `app.config.ts`.
- Compose: `POSTGRES_DB` / `DATABASE_URL` database name `wings_of_power`. Do not remove Prometheus, Grafana, or coturn yet (T-BE-035).
- Rewrite `README.md` as Wings setup: yarn, `.env`, `docker compose up -d postgres redis`, `npx prisma migrate dev`, `yarn cmd seed`, `yarn start:dev`, Swagger `/api/docs`. Delete Stripe CLI instructions.

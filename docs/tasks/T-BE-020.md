# T-BE-020 — Kindness leaderboard

**Status:** done
**Module:** `src/modules/points`
**Depends on:** T-BE-017
**Priority:** P0

## Goal

A student sees a kindness leaderboard of nicknames and avatars, not hero art.

## Scope

`GET /api/student/leaderboard?scope=class|school`. Default `class`: the student’s approved class. `school`: same `school_id`. Rank by `SUM(PointsLedger.kindness_amount)` descending. Only `source = GAME_KINDNESS` should carry a non-zero `kindness_amount`; still sum the column, do not sum `amount`.

Each item: `userId`, `nickname` (fallback username), `avatarUrl`, `kindnessPoints`, `rank`. Do not return `real_name`, hero id, or hero art (decision A5).

Ties share the next rank using competition rank (1, 2, 2, 4). Include the caller even at 0. Paginate. Hide `INACTIVE` and soft-deleted users.

## Out of scope

- Writing kindness points (T-BE-026).
- Teacher award rows on this board.
- A teacher leaderboard route (not in `docs/API.md`).

## Notes

- Standard competition ranking (1, 2, 2, 4) applied before paginating.

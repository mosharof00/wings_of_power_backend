# T-BE-005 — Student class-code join and login

**Status:** done
**Module:** `src/modules/auth`
**Depends on:** T-BE-004
**Priority:** P0

## Goal

A student can preview a class code, register into a pending membership, select a starter hero, and log in only after the account is active.

## Scope

- Join-code looks up `ClassCode`. Unknown code → 404 with message `WRONG_CODE`. `EXPIRED` or `REVOKED`, or `expires_at` in the past → 422 `EXPIRED_CODE`. Success returns `{ className, teacherName, classId }`.
- Register creates `User` (`STUDENT`, `PENDING`, `school_id` from the class) and `ClassMembership` (`PENDING`, `joined_via_code_id`). Duplicate username → 409. Bad code → 422. Returns `{ user, accessToken }`.
- Select-hero allows only a hero with `unlock_stories_required = 0`, or a hero already in `StudentHeroUnlock`. Otherwise 403. Sets `selected_hero_id` and writes the unlock row.
- Login with username/password. Unknown or bad password → 401. `PENDING` or `INACTIVE` → 422 `PENDING` (inactive uses the same 422 so the app stays on the pending/blocked state; message text includes the status). `ACTIVE` returns `{ accessToken, user }`. `remember` may be accepted and ignored.
- `GET /api/auth/me` for a student includes status, class membership summary, and selected hero.

Tests insert their own `School`, `Class`, `ClassCode`, and `Hero` through the mocked or test Prisma client. No admin class API in this task.

## Notes

Join-code matches `ClassCode.code` exactly after trim. Unknown is 404 `WRONG_CODE`. `EXPIRED`, `REVOKED`, or a past `expires_at` is 422 `EXPIRED_CODE`. An active code returns `className`, `teacherName` (the teacher’s real name), and `classId`.

Register stores `STUDENT` / `PENDING`, `school_id` from the class, nickname, and real name, plus a `PENDING` membership with `joined_via_code_id`. Duplicate username is 409. A bad code on register is 422. The response is `{ user, accessToken }` so setup and hero select work before approval. Password is at least 8 characters and must match confirm (account-setup screen). `remember` is accepted on login and ignored.

Select-hero is JWT-only and requires `STUDENT`. A hero with `unlock_stories_required` other than 0 is 403 unless `StudentHeroUnlock` already has the row. Success writes the unlock and sets `selected_hero_id`.

Student login looks up `username`, not email. A bad password or a non-student is 401. `PENDING` and `INACTIVE` are 422 and the message is the status. `ACTIVE` returns `{ accessToken, user }`. `GET /api/auth/me` adds the latest class membership summary and the selected hero; staff with no membership still get `class: null`.

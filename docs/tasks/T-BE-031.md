# T-BE-031 — OpenAPI export

**Status:** todo
**Module:** Swagger export
**Depends on:** T-BE-008, T-BE-010, T-BE-012, T-BE-018, T-BE-019, T-BE-020, T-BE-023, T-BE-026
**Priority:** P0

## Goal

Generate `docs/openapi.json` from the Nest controllers so the app and dashboard can switch off mocks.

## Scope

Add `yarn openapi:export`. It creates the Nest application the same way `main.ts` does (global prefix, validation pipe, bearer auth) and `SwaggerModule.createDocument`, then writes `wings_of_power_backend/docs/openapi.json`. It does not listen, or it listens and closes. Do not hand-write the JSON.

Every P0 controller from `docs/API.md` has `@ApiTags`, `@ApiBearerAuth` where guarded, and DTO `@ApiProperty`. Add missing decorators only on controllers that already exist. Do not add routes.

The script’s success check: the document contains these paths (method + path):

- `/api/auth/student/join-code`
- `/api/auth/me`
- `/api/stories`
- `/api/quizzes/{quizId}/attempts`
- `/api/student/home`
- `/api/student/leaderboard`
- `/api/safe-space/reports`
- `/api/teacher/classes`
- `/api/admin/students`
- `/api/admin/stories`
- `/api/game/queue`
- `/api/admin/game/eligibility-config`

Socket events are not in OpenAPI. Point at `docs/REALTIME.md` in the script’s log line.

## Out of scope

- P1 and P2 routes may appear if the controllers exist. Do not block on them.
- A CI job (the repo has none). Mention the command in `README.md` in one line.
- Editing `docs/API.md`.

## Allowed files

- `src/openapi.ts` (or `scripts/openapi.ts` if that fits `ts-node` better)
- `package.json` (script only)
- `README.md` (one sentence and the command)
- controller files **only** to add `@ApiProperty` / `@ApiTags` that are missing on DTOs and controllers already in the tree
- `docs/openapi.json` (generated, committed)
- this task file (Status / Notes)

If a DTO is missing `@ApiProperty`, editing that DTO file is allowed. List every extra file in Notes.

## Endpoints

No new routes. The export reflects the routes already implemented.

## Entities

None.

## Required tests

No new Jest suite. The export command is the test: it exits 0 and the paths above are in the file.

`yarn test` and `yarn test:e2e` still pass.

## Done when

From `wings_of_power_backend/`:

```bash
yarn openapi:export
yarn lint
yarn test
yarn test:e2e
yarn build
```

Confirm the path list with a search in `docs/openapi.json`. Set **Status** to `done` and write **Notes**.

This task is the **contract-ready** gate together with green T-BE-028, T-BE-029, and T-BE-030. Do not mark the milestone in those files; state in Notes that export succeeded.

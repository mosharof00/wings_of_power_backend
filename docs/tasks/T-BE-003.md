# T-BE-003 — Database and migration baseline

**Status:** done
**Module:** Prisma
**Depends on:** T-BE-002
**Priority:** foundation

## Goal

Replace the hurricane schema with the Wings schema in `docs/DATABASE.md`, and keep the TypeScript build green.

## Scope

Before writing the schema, record these in `docs/DECISIONS.md` and update `docs/DATABASE.md` to match:

- `AuthCode`: `id`, `email`, `purpose` enum `VERIFY_EMAIL | RESET_PASSWORD`, `code_hash`, `expires_at`, `used_at`, timestamps.
- `User.school_id` optional until `POST /api/auth/school`.
- `GamePackStory` join (`pack_id`, `story_id`) unique, instead of `story_ids String[]`.
- Prisma enums for the closed sets named in `docs/PLAN.md` (no new members).

Then:

- Rewrite `prisma/schema.prisma` to `docs/DATABASE.md` plus those three notes. IDs `cuid()`. Timestamps on every model. Points are `Int`. Soft-delete `deleted_at` only where the database doc allows it. Safe Space reports are not soft-deleted.
- Delete `prisma/migrations/20261012081508_init`. Add one baseline migration SQL (`prisma migrate diff --from-empty --to-schema-datamodel prisma/schema.prisma --script`). Keep `migration_lock.toml`.
- Soft-delete via a Prisma client extension on `User`, `Story`, `Chapter`, `Class`, `Badge`, `KindnessCornerItem`, `Notification`: default reads hide `deleted_at != null`; `delete` sets `deleted_at`. Do not use `$use`. Delete the old `softdelete.middleware.ts` behavior (the `Note` model and `deleted_at = false` checks).
- Rewrite `UserRepository` to the new fields: find by id/email/username, create, update password hash. Remove `roleUser` methods.
- Delete `ucode` repository and unwire it.
- `AbilityFactory` must compile with no `Role` / `Permission` models. Empty ability is enough. Do not seed CASL.
- `SeedCommand` stays a no-op that compiles.
- `AuthService` / controller compile against the new client. Wings flows are **not** this task. Methods that no longer make sense throw `NotImplementedException`. Specs match that.

## Notes

Recorded D25–D29 in `docs/DECISIONS.md` before the schema, and updated `docs/DATABASE.md`: `AuthCode`, nullable `User.school_id`, `GamePackStory`, and the five closed-set enums (`QuizAttemptStatus`, `ReadingMode`, `GameRoundPhase`, `TicketStatus`, `MediaType`).

`prisma/schema.prisma` is the Wings schema. IDs are `cuid()` except the composite keys already in the database doc (`StudentHeroUnlock`, `ChapterProgress`, `StudentBadge`, `GameEligibilityConfig`). Every model has `created_at` and `updated_at`. Points are `Int`. `deleted_at` is only on User, School, Class, Story, Chapter, Badge, KindnessCornerItem, and Notification. Safe Space reports have no `deleted_at`. Password column is `password_hash`. `Role` is the enum on `User`.

Replaced `prisma/migrations/20261012081508_init` with `prisma/migrations/20261031085000_wings_baseline` (`prisma migrate diff --from-empty`). `migration_lock.toml` stays. `npx prisma migrate reset --force` applied that baseline to the local `wings_of_power` database.

Soft-delete is a Prisma client extension in `src/prisma/middleware/softdelete.middleware.ts`, applied by `PrismaService`. Reads of User, Story, Chapter, Class, Badge, KindnessCornerItem, and Notification hide `deleted_at != null`. `delete` and `deleteMany` set `deleted_at`. A local check created a user, deleted it, and confirmed `findFirst` / `findUnique` hide the row while the column is set. That script was not kept.

`UserRepository` finds by id, email, and username, creates a user, and updates `password_hash`. `getUserDetails` is the id lookup the existing guards already call. `roleUser` methods and the `ucode` repository are gone.

`AbilityFactory` builds an empty ability and does not reference `Role` or `Permission` models. `SeedCommand` is still the T-BE-027 no-op. Auth service methods throw `NotImplementedException` (HTTP 501). Specs expect that and do not touch `ucode`, `roleUser`, or `type`.

Extra files, so the project still typechecks after `UserType` and the `Role` model disappeared:

- `src/modules/auth/dto/create-user.dto.ts` and `create-user-res.dto.ts` no longer import `UserType`.
- `src/common/middleware/authgates.middleware.ts` no longer queries `prisma.role`.
- `src/common/guard/role/roles.guard.ts` compares `user.role` instead of `user.type`.

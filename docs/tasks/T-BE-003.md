# T-BE-003 — Database and migration baseline

**Status:** todo
**Module:** Prisma
**Depends on:** T-BE-002
**Priority:** foundation

## Goal

Replace the hurricane schema with the Wings schema in `docs/DATABASE.md`, and keep the TypeScript build green.

## Scope

Before writing the schema, record these in `docs/DECISIONS.md` and update `docs/DATABASE.md` to match:

- `AuthCode`: `id`, `email`, `purpose` enum `VERIFY_EMAIL | RESET_PASSWORD`, `code_hash`, `expires_at`, `used_at`, timestamps.
- `User.school_id` optional until `POST /api/auth/school`.
- `GamePackStory` join (`pack_id`, `story_id`) unique, instead of `story_ids String[]`.
- Prisma enums for the closed sets named in `docs/PLAN.md` (no new members).

Then:

- Rewrite `prisma/schema.prisma` to `docs/DATABASE.md` plus those three notes. IDs `cuid()`. Timestamps on every model. Points are `Int`. Soft-delete `deleted_at` only where the database doc allows it. Safe Space reports are not soft-deleted.
- Delete `prisma/migrations/20261012081508_init`. Add one baseline migration SQL (`prisma migrate diff --from-empty --to-schema-datamodel prisma/schema.prisma --script`). Keep `migration_lock.toml`.
- Soft-delete via a Prisma client extension on `User`, `Story`, `Chapter`, `Class`, `Badge`, `KindnessCornerItem`, `Notification`: default reads hide `deleted_at != null`; `delete` sets `deleted_at`. Do not use `$use`. Delete the old `softdelete.middleware.ts` behavior (the `Note` model and `deleted_at = false` checks).
- Rewrite `UserRepository` to the new fields: find by id/email/username, create, update password hash. Remove `roleUser` methods.
- Delete `ucode` repository and unwire it.
- `AbilityFactory` must compile with no `Role` / `Permission` models. Empty ability is enough. Do not seed CASL.
- `SeedCommand` stays a no-op that compiles.
- `AuthService` / controller compile against the new client. Wings flows are **not** this task. Methods that no longer make sense throw `NotImplementedException`. Specs match that.

## Out of scope

- Implementing login, join-code, or HTTP behavior (T-BE-004, T-BE-005).
- Product seed rows (T-BE-027).
- New routes.

# T-BE-027 — Dev seed

**Status:** todo
**Module:** `src/command/seed.command.ts`
**Depends on:** T-BE-003
**Priority:** P0

## Goal

`yarn cmd seed` loads the demo school from `docs/DATABASE.md` so the app and dashboard can log in.

## Scope

Idempotent seed (skip when the school name already exists):

| Row | Data |
|-----|------|
| School | Demo Elementary |
| Admin | `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD`, `ACTIVE`, email verified, `school_id` set |
| Teacher | `SEED_TEACHER_EMAIL` / `SEED_TEACHER_PASSWORD`, `ACTIVE`, assigned to the class, `canAccessSafeSpace: true` |
| Class | Grade 4 · Amber, `AGE_6_9`, teacher set |
| Code | `WING-4320` `ACTIVE` |
| Students | one `PENDING` and one `ACTIVE` (password `SEED_STUDENT_PASSWORD`), active student has an `APPROVED` membership |
| Heroes | Faith, Harold, Ralph, Michele, Samantha, Michael, Chi. `unlock_stories_required` 0 for the first, 2 for the others. `PowerCode` values from the database doc, one each, skip a code only if you run out of heroes |
| Badges | all six `BadgeCode` values, empty `criteria_json` `{}` |
| Point rules | `STORY_QUESTION` 1, `KINDNESS_ROUND` 50, `TEACHER_AWARD_MAX` 5 |
| Eligibility | 2 / 6 / 70 |
| Story | one published Kindness story, age `AGE_6_9`, at least 2 chapters, pages, no requirement for a real audio file (`ChapterAudio` optional) |
| Quizzes | one `CHAPTER` and one `CHECKPOINT` on chapter 1, two MCQ questions each, one correct option |
| Pack | one published pack linked with `GamePackStory`, one question for each of Q1–Q4 |

Passwords are bcrypt hashes. Do not print passwords. Do not seed Safe Space reports.

## Out of scope

- HTTP endpoints.
- Production data.
- Badge criteria that auto-unlock.

## Allowed files

- `src/command/seed.command.ts`
- `src/command/seed.data.ts`
- `src/cmd.ts` (providers only if the command needs a new import)
- this task file (Status / Notes)

## Endpoints

None. Command: `yarn cmd seed`.

## Entities

The rows above. No new models.

## Required tests

A spec that runs the seed function against a mocked Prisma `create` / `findFirst` and asserts:

- it does not create a second school when one exists.
- admin email is the env value.
- badge count in the payload is 6.
- point-rule values are 1, 50, and 5.

If mocking the transaction is too heavy, extract pure `buildSeedPlan()` that returns the row descriptions and unit-test that. The command stays a thin writer.

When `DATABASE_URL` is up, `yarn cmd seed` exits 0 and a second run does not throw. Set **Status** to `done` and write **Notes**.

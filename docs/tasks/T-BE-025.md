# T-BE-025 — Game gateway, matchmaking, reconnect

**Status:** todo
**Module:** `src/modules/game`
**Depends on:** T-BE-024
**Priority:** P0

## Goal

Socket.io can authenticate a student, fill a queue, start a countdown, and restore a match after reconnect.

## Scope

One gateway on the default namespace `/`. Handshake `auth.token` is the JWT. Reject missing or invalid tokens. On connect, join `user:{userId}`. Students who are not `ACTIVE` are disconnected.

Use the in-memory queues from T-BE-024. Fill rules: `ONE_V_ONE` needs 2, `FIVE_V_FIVE` needs 10, random split into teams A and B. `SINGLE` already has a match from REST. When a lobby fills, create `GameMatch`, `GameTeam`, `GameParticipant` (hero id from `selected_hero_id`), set tickets `MATCHED`, join sockets to `match:{matchId}`, emit `match:found`, then `match:countdown` with `deadlineAt` 3 seconds ahead. When the deadline passes, set phase `PLAYING` and emit `match:phase`. Do not deal questions here (T-BE-026).

Events this task handles: `queue:join`, `queue:cancel`, `queue:update`, `queue:error`, `match:found`, `match:countdown`, `match:phase`, `match:snapshot`, `match:leave`, `match:peer_left`. Payloads match `docs/REALTIME.md`. Ineligible → `queue:error` `INELIGIBLE`. Duplicate queue → `ALREADY_QUEUED`.

Leave: set `left_at`, emit `match:peer_left`, do not cancel the match for others.

Reconnect: same JWT, open participant, rejoin `match:{id}`, emit `match:snapshot` with `serverNow`, phase, teams, and `you`. Finished or gone → snapshot `phase: FINISHED` or error `MATCH_GONE`.

On module init, set matches whose phase is not `FINISHED` or `CANCELLED` to `CANCELLED` (process restart). Timers are `setTimeout` keyed by match id. Clear them on advance.

No Redis adapter. No `/game` namespace.

## Out of scope

- Voice, spectators, cross-school matchmaking.

## Required tests

Use a mocked socket server or call the service methods the gateway calls:

- invalid token is rejected.
- two `ONE_V_ONE` tickets produce one match and `match:found` payload with two members.
- `FIVE_V_FIVE` does not start at 9 players.
- leave emits peer-left and leaves phase unchanged.
- snapshot for a non-participant is `MATCH_GONE`.
- boot cancel marks an old `PLAYING` row `CANCELLED` (call the init method directly).

# T-BE-014 — Teacher chapter-quiz CMS

**Status:** done
**Module:** `src/modules/quizzes`
**Depends on:** T-BE-012, T-BE-006
**Priority:** P0

## Goal

A teacher can read and replace the chapter quiz (and its checkpoint sibling) for a chapter. Decision A4: this API is P0 even if the current teacher UI is the game-pack builder.

## Scope

`QuizzesModule`. `GET/PUT /api/teacher/chapters/:chapterId/quiz`.

PUT body is the full question list. Upsert one `Quiz` with `kind: CHAPTER` for that chapter, owned by the teacher (`created_by_id`). Replace questions and options (do not leave orphan options). Each question has `type` `MCQ | TRUE_FALSE | FREE_TEXT`, `prompt`, optional `hint` and `explanation`, ordered options with `label` and `is_correct`. MCQ and true/false need at least one correct option. Free text may have zero options.

The same PUT accepts an optional `checkpoint` object with the same question shape and upserts `kind: CHECKPOINT` on that chapter. If `checkpoint` is omitted, leave any existing checkpoint untouched.

Teacher must be in the same school as the story. Do not require the teacher to be the story’s author (admin uploads stories).

GET returns questions **with** `is_correct` (CMS). Student GET must not (T-BE-015).

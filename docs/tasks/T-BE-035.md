## Goal

Compose runs Postgres, Redis, and the API. The image can start the compiled app. Coturn, Prometheus, and Grafana are gone.

## Scope

Not required for contract-ready. Required for deploy-ready.

- `docker-compose.yml` services: `app`, `postgres`, `redis` only. Database name `wings_of_power` (from T-BE-002). No `turnserver`, `prometheus`, `grafana`. Delete `prometheus.yml` and `dockerfiles/coturn/`.
- `Dockerfile`: multi-stage build, `yarn install`, `npx prisma generate`, `yarn build`, runtime `node dist/src/main`. Do not copy a developer `.env` into the image. Document required env in `README.md`.

- `.dockerignore` includes `.env`, `node_modules`, `dist`, `prisma/generated` if generate runs inside the image.

Do not add a process manager, Kubernetes manifests, or a CI workflow.

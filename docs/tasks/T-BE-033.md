# T-BE-033 — Kindness Corner admin (P1)

**Status:** done
**Module:** `src/modules/content`
**Depends on:** T-BE-011, T-BE-012
**Priority:** P1

## Goal

An admin can create and publish Kindness Corner items. Students do not get a list route.

## Scope

Not required for contract-ready.

CRUD `/api/admin/kindness-corner`. Fields: `title`, `media_url`, `media_type` `IMAGE | VIDEO`, `status`. Media URL comes from `POST /api/uploads` with `KINDNESS_MEDIA` (already allowed in T-BE-011). This task does not upload.

List is paginated. Create defaults to `DRAFT`. Patch can publish. Delete sets `deleted_at` (model allows it).

Do not add `GET /api/content/kindness-corner`. There is no student screen.

## Out of scope

- Student home tile behavior.
- A second upload endpoint.
- Video transcoding.

## Endpoints

| Method | Path | Roles |
|--------|------|-------|
| GET | `/api/admin/kindness-corner` | ADMIN |
| POST | `/api/admin/kindness-corner` | ADMIN |
| PATCH | `/api/admin/kindness-corner/:id` | ADMIN |
| DELETE | `/api/admin/kindness-corner/:id` | ADMIN |

The contract says CRUD and does not name PATCH vs PUT. Use PATCH for updates and DELETE for soft-delete. Write that choice in Notes.

## Entities

`KindnessCornerItem`.

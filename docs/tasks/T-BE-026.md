# T-BE-026 — Rounds, powers, and shootout

**Status:** todo
**Module:** `src/modules/game`
**Depends on:** T-BE-025
**Priority:** P0

## Goal

The server runs Q1–Q4 and the shootout, writes kindness points, and finishes the match.

## Scope

Extend the gateway and a `RoundService`. Questions come from a `PUBLISHED` `GameQuestionPack` for the school and age group. If none exists, use an in-memory scripted pack of one question per `RoundType` so `SINGLE` still runs. Do not build pack CRUD (T-BE-032).

Server timers (`deadlineAt` on each emit). Clients do not advance the phase.

| Round | Behavior |
|-------|----------|
| Q1 | `round:intro`, `round:question` (no correct index), first `round:buzz` wins, then 10s `round:answer`. Others get `round:waiting`. |
| Q2 | 60s free text. Correctness is not auto-graded. Award kindness from `PointRule` `KINDNESS_ROUND` or **50** (D8) as `PointsLedger` `GAME_KINDNESS` with `amount` and `kindness_amount` both 50. One row per participant per Q2 round. |
| Q3 | Buzz/answer 10s. `power:use` once (`power_used`). Emit `power:effect`. Support `removedOptions`, `extraMs`, `hint`, `freeze` as labels only; pick the effect from `PowerCode` with a fixed map written in Notes. `power:help_request` / `power:help_suggest` relay to teammates and do not reveal the correct index. |
| Q4 | 20s `round:vote`. `round:vote_update` is counts only. At deadline, majority wins. In `ONE_V_ONE` / `SINGLE` the one voter’s choice is the choice (D9). |
| Shootout | `shootout:start` for the shooter the round designates (correct trivia earns the shot, D6). `shootout:swipe` `{ made }` accepted only from that participant before `deadlineAt`. Persist `GameShootout`. `xp_awarded` 3 on make (D8 baskets), else 0. |

Then `round:complete` and, after the last round, `match:finished` with team scores. Set `finished_at` and `winner_team_id` (higher `score_xp`, tie → null). `safespace:enter` writes `SafeSpaceVisit` and does **not** pause timers. `safespace:exit` emits `match:snapshot`.

Timeouts advance the phase inside the server.

Wrong caller, late answer, or second power → `queue:error`-style ack or a thrown socket error with code `FORBIDDEN` or `TOO_LATE`. Do not apply the action.

## Out of scope

- Real-time physics. `made` is trusted inside the window (REALTIME.md).
- Redis, BullMQ timers, bots.
- Changing REST eligibility.

## Required tests

Drive `RoundService` without a live socket:

- second buzz does not replace the winner.
- answer after `deadlineAt` is rejected.
- Q2 writes `GAME_KINDNESS` with `kindness_amount` 50 once.
- Q4 tally hides choices until resolve; majority wins; 1v1 uses the single vote.
- second `power:use` is rejected.
- swipe from a non-shooter is rejected.
- `safespace:enter` does not change `deadlineAt`.
- finish sets `winner_team_id` from `score_xp`.

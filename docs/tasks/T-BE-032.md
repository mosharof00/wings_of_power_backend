# T-BE-032 — Game question packs (P1)

**Status:** done
**Module:** `src/modules/game`
**Depends on:** T-BE-012, T-BE-024
**Priority:** P1

## Goal

A teacher can build a four-round question pack and link it to stories. An admin can do the same.

## Scope

Not required for contract-ready.

CRUD:

- Teacher: `/api/teacher/game-packs` and `/api/teacher/game-packs/:id`
- Admin: `/api/admin/game-packs` and `/api/admin/game-packs/:id`

Pack fields: `title`, `age_group`, `status` `DRAFT | PUBLISHED`, story ids (written as `GamePackStory` rows). Questions: `round_type` covering Q1–Q4, `sort_order`, `type`, `prompt`, `options_json` `{ options, correctIndex }`, optional `meta_json`. Publishing requires at least one question for each `RoundType`. A pack that skips a round → 400 on publish, allowed while `DRAFT`.

Teacher packs are limited to the caller’s school. Story ids must be published stories in that school.

`SINGLE` / matchmaking already falls back to a scripted pack when none is published (T-BE-026). When a published pack exists, that task’s selector should prefer it. If T-BE-026 is not done yet, only persist packs. If it is done, change the selector in `round.service.ts` to prefer a published pack for the student’s age group. That one function is in the allowed list.

`docs/API.md` says CRUD. DELETE soft-deletes by setting status `DRAFT` is wrong. There is no `deleted_at` on packs. DELETE removes the pack row (hard delete) only when it is `DRAFT`. Published delete → 409. Record that in `docs/DECISIONS.md` before coding.
